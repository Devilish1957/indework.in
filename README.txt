INDEWORK GITHUB PAGES MIRROR

Files:
- index.html
- styles.css
- script.js

Upload these three files to the root of your GitHub Pages repository.
The contact form is front-end only and opens the visitor's email client; it does not store submissions.

The page reproduces the structure/content of the public Wix IndeWork page, while using a self-contained responsive design rather than Wix-hosted components.


LOGO
----
The IndeWork wordmark is included at assets/indework-logo.svg and is used as the
site header logo and favicon. It is self-contained SVG, so it works on GitHub
Pages without Wix assets.
